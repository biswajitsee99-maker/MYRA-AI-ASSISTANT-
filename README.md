# 📖 About MYRA

MYRA AI Assistant is a powerful AI-powered desktop assistant built entirely in Python.

MYRA combines advanced voice interaction, intelligent automation, computer vision, screen understanding, system control, website generation, and productivity tools into a single modern AI platform.

Designed for creators, developers, students, professionals, and power users, MYRA helps users interact naturally with their computer through voice commands and intelligent AI automation.

```bash

```

Expected Output:

```text
Python 3.11.x
```

---

## Step 3 - Verify Pip

```bash
pip --version
```

---

## Step 4 - Install MYRA

```bash
pip install myra-ai-assistant
```

---

## Step 5 - Launch MYRA

```bash
myra
```

or

```bash
python -m myra_ai_assistant
```

## Optional - Enable Offline Voice Controls

Install the optional voice dependencies from the project directory:

```bash
python -m pip install -e ".[voice]"
```

Launch the desktop app:

```bash
myra-desktop
```

Use **Start Mic** to dictate commands and **Speak replies** to enable local text-to-speech. Voice recognition uses PocketSphinx offline; it does not send microphone audio to an online speech-recognition service. Microphone access must be enabled in Windows privacy settings.

## Demo Login and Premium Activation Screen

The desktop app includes a visual login screen and an activation-key form for demonstration. The login does not authenticate accounts, and the activation form does not validate keys or enable Premium; no credentials or keys are stored. A real account or licensing service must be configured for those features.

## Live Dashboard and Windows Controls

The desktop dashboard refreshes operating system, logical processor, and memory usage information every five seconds. Use **Refresh Dashboard** to update immediately. The allowlisted chat and sidebar actions can open Notepad, Calculator, File Explorer, and Paint, report system status, and send volume up/down or mute media-key actions on Windows.

AI responses are currently local demo responses, not generated by an AI provider. Screen reading and computer vision are not connected.

## Windows Controls

The desktop chat supports a limited allowlist of local actions:

* `open notepad`, `open calculator`, `open file explorer`, or `open paint`
* `system status`
* `volume up`, `volume down`, or `mute volume`

MYRA does not execute arbitrary shell commands. Volume controls send the corresponding media-key action to Windows; `mute volume` toggles mute. The application and volume commands require Windows.
